# 1.3 Wireless Principles, Wi-Fi Generations & RF Architecture

## Mental Models: Split-MAC Architecture
* **The Lightweight AP (LAP):** The **Ears and Mouth**. Listens for radio waves, transmits beacons, and decrypts raw 802.11 airwaves in real-time.
* **The Controller (WLC):** The **Brain**. Lives in the datacenter, validates user security credentials, decides client roaming, and adjusts RF power dynamically.

---

## 802.11 Wi-Fi Standards Evolution

| Generation | Standard | Operating Frequencies | Max Data Rate | Key Architectural Mechanisms |
|---|---|---|---|---|
| **Legacy** | 802.11b | 2.4 GHz | 11 Mbps | DSSS modulation |
| **Legacy** | 802.11a | 5 GHz | 54 Mbps | OFDM modulation |
| **Legacy** | 802.11g | 2.4 GHz | 54 Mbps | OFDM modulation, backwards-compatible with 11b |
| **Wi-Fi 4** | 802.11n | 2.4 GHz & 5 GHz | 600 Mbps | MIMO (up to 4x4), 40 MHz channel bonding |
| **Wi-Fi 5** | 802.11ac| 5 GHz strictly | 6.93 Gbps | 256-QAM, 80/160 MHz channels, Downlink MU-MIMO |
| **Wi-Fi 6** | 802.11ax| 2.4 GHz & 5 GHz | 9.6 Gbps | OFDMA, Downlink + Uplink MU-MIMO, 1024-QAM, BSS Color, TWT |
| **Wi-Fi 6E** | 802.11ax| 2.4, 5 & **6 GHz** | 9.6 Gbps | 1200 MHz spectrum expansion, Greenfield, Zero DFS |
| **Wi-Fi 7** | 802.11be| 2.4, 5 & 6 GHz | ~46 Gbps | 320 MHz channels, 4096-QAM, MLO (Multi-Link Operation) |

* **[EXAM-FACT]** **MIMO vs. MU-MIMO:**
  * **MIMO:** Transmits/receives multiple spatial streams across multiple antennas to **one client** at a time.
  * **MU-MIMO:** Transmits spatial streams to **multiple clients concurrently** (802.11ac = Downlink only; 802.11ax = Downlink AND Uplink).
* **[EXAM-FACT]** **OFDMA:** Subdivides a channel into Resource Units (RUs), serving multiple small client requests in parallel with low latency.

## RF Frequencies, Channels & Channel Bonding Traps

| Band | Channel Count | Non-Overlapping Channels | Channel Bonding Support | Interference Exposure |
|---|---|---|---|---|
| **2.4 GHz** | 11 (US) / 13 (EU)| **1, 6, 11** (20 MHz each) | **Do not bond** to 40 MHz! | High (Microwaves, Bluetooth, baby monitors) |
| **5 GHz** | 24+ channels | All 24+ channels non-overlap | 40 MHz, 80 MHz, 160 MHz | Moderate (Radar DFS interruptions) |
| **6 GHz** | Massive spectrum | Up to fourteen 80 MHz channels | 80 MHz, 160 MHz, 320 MHz | None (Greenfield, Zero legacy clients, No DFS) |

```
2.4 GHz Non-Overlapping Layout:
Channel: [ 1 ] ----- [ 6 ] ----- [ 11 ]  (Requires 25 MHz center separation)
```

* **[TRAP]** **2.4 GHz 40 MHz Bonding Trap:** Bonding two 20 MHz channels into 40 MHz in 2.4 GHz takes over 80% of the entire frequency space. It causes massive Co-Channel Interference (CCI) and is unsupported in enterprise design.
* **[EXAM-FACT]** **Dynamic Frequency Selection (DFS):** If an AP operating on 5 GHz detects radar pulses, it must vacate the channel immediately and move clients to another frequency.

## RF Math, Antennas & Propagation Physics

| Metric / Term | Physical Definition | Standard Value / Optimal Range |
|---|---|---|
| **RSSI** | Received Signal Strength Indication | $-30\text{ dBm}$ (Excellent), **$-67\text{ dBm}$ (VoWLAN minimum)**, $-80\text{ dBm}$ (Unusable) |
| **Noise Floor** | Ambient background RF energy | Typically $-90\text{ dBm}$ to $-100\text{ dBm}$ |
| **SNR** | Signal-to-Noise Ratio | $\mathbf{\text{RSSI} - \text{Noise}}$. Recommended **$\ge 25\text{ dB}$** for voice/video |
| **Wavelength ($\lambda$)**| Spatial period of RF wave | Inversely proportional to frequency ($\lambda = c / f$) |

### Antenna Types Comparison

| Antenna Type | Radiation Pattern | Visual Shape | Common Deployment |
|---|---|---|---|
| **Omnidirectional** | $360^\circ$ horizontal coverage | Torus / Donut | Standard indoor ceiling mounts |
| **Directional (Patch/Yagi/Dish)**| Focused narrow beam | Cone / Flashlight beam | High ceilings, warehouse aisles, Point-to-Point bridges |

### Environmental RF Propagation

```
*  Wave hits drywall/concrete/water --> ABSORPTION (Energy converts to heat; signal weakens)
*  Wave hits large sheet metal/mirror --> REFLECTION (Multipath interference)
*  Wave passes through glass/acrylic   --> REFRACTION (Bending of wave angles)
*  Wave hits irregular rough surfaces --> SCATTERING (Diffusion into multi-angle fragments)
```

* **[EXAM-FACT]** **Co-Channel Interference (CCI):** APs on the identical channel share airtime, causing CSMA/CA backoff delays.
* **[EXAM-FACT]** **Adjacent Channel Interference (ACI):** APs on partially overlapping channels bleed energy, corrupting frame transmissions.

## Wireless Topologies & Terminology

| Acronym | Term Name | Architectural Scope |
|---|---|---|
| **BSS** | Basic Service Set | A single AP servicing wireless clients within its footprint |
| **BSSID** | Basic Service Set Identifier | The Layer 2 radio MAC address of the AP servicing that BSS |
| **BSA** | Basic Service Area | The physical RF coverage boundary of a BSS |
| **ESS** | Extended Service Set | Two or more BSS cells sharing an SSID via wired switch infrastructure |
| **SSID** | Service Set Identifier | Broadcast human-readable network name (up to 32 characters) |
| **IBSS** | Independent BSS | Ad-hoc wireless network directly between clients (No AP) |
| **WGB** | Workgroup Bridge | Cisco AP acting as a wireless client to bridge wired Ethernet devices |

### Client Connection Sequence

```
[ 1. Discovery ]       Client scans actively (Probe Requests) or passively (Listens for AP Beacons)
       |
[ 2. Authentication ]  802.11 Open System frame exchange
       |
[ 3. Association ]     Client sends Association Request; AP allocates radio buffers and responds
       |
[ 4. Key Handshake ]   4-Way Handshake (EAPOL) generates encryption keys (PTK) via WPA2/WPA3
```

## Wireless Security Standards

| Standard | Encryption Cipher | Key Management Protocol | Known Vulnerabilities / Features |
|---|---|---|---|
| **WEP** | RC4 (Static 24-bit IV) | Pre-Shared Key | Deprecated; crackable in minutes |
| **WPA** | RC4 dynamic | TKIP | Deprecated; temporary fix for WEP |
| **WPA2** | **AES** (Strong) | CCMP | Standard deployment; vulnerable to offline dictionary capture |
| **WPA3** | **AES / CNSA 192-bit** | **SAE** (Simultaneous Authentication of Equals)| Immune to offline dictionary attacks; enforces PMF (802.11w) |

## Split-MAC Architecture & AP Operating Modes

| MAC Function | Local Lightweight AP (LAP) | Centralized Controller (WLC) |
|---|---|---|
| **Frame Beacons & Probe Responses** | **Yes** | No |
| **Packet Buffering & L2 802.11 ACKs** | **Yes** | No |
| **Real-Time Layer 2 Frame Encryption**| **Yes** | No |
| **Client Association & Re-association**| No | **Yes** |
| **802.1X / EAP Authentication** | No | **Yes** |
| **802.11 to 802.3 Frame Translation** | No | **Yes** (Local mode) |
| **Radio Resource Management (RRM)** | No | **Yes** |

* **[EXAM-FACT]** **CAPWAP Ports:**
  * **Control Plane:** UDP Port **5246** (DTLS encrypted mandatory).
  * **Data Plane:** UDP Port **5247** (Encapsulates user payload; DTLS optional).
* **[EXAM-FACT]** **AP Modes:**
  * **Local Mode (Default):** Normal client serving. All user traffic tunnels through CAPWAP to WLC.
  * **FlexConnect Mode:** Switches client frames locally on branch switches if WAN connection to WLC fails.
  * **Bridge / Mesh Mode:** Connects APs wirelessly point-to-point without physical Ethernet cables.
  * **Monitor Mode:** Radio does not serve clients; acts full-time as an IDS/IPS sensor.
  * **Sniffer Mode:** Captures raw 802.11 packets on a channel and streams them to Wireshark.
  * **Rogue Detector Mode:** AP radio disabled; listens solely on wired network broadcasts to catch rogue MACs.

### WLC Logical Interfaces & LAG Constraint

| Interface Name | Logical Nature | IP Address Assigned | Operational Purpose |
|---|---|---|---|
| **Management** | Static | Routable IP | Web GUI, SSH, AAA RADIUS authentication, CAPWAP termination |
| **Virtual** | Static / Fake | Fictitious IP (e.g., `192.0.2.1`) | Mobility management, guest captive portal redirection, DHCP relay |
| **Dynamic** | User-created | Routable subnet IP | Mapped directly to specific WLAN SSIDs and distribution VLANs |
| **Service Port**| Dedicated physical | Out-of-band isolated IP | Maintenance and emergency access during primary link failure |

* **[TRAP]** **WLC LAG Architectural Constraint:**
  * Cisco WLC supports only **one single LAG bundle** across its physical distribution ports.
  * Upstream switchports must have EtherChannel statically forced to mode `on` (no LACP/PAgP in classic versions).
