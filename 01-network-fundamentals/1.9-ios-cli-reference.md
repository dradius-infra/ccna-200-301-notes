# 1.9 Master Cisco IOS CLI Reference (Domain 1 Scope)

## Baseline System & Security Configuration

```cisco
! Enter Global Configuration mode:
configure terminal

! System identity & Privileged EXEC security:
hostname SW1
enable secret cisco123               ! Uses Type 5 MD5 or Type 8/9 PBKDF2/scrypt
service password-encryption          ! Obfuscates plain text passwords (Type 7)

! Prevent CLI freezing on typo broadcast DNS requests:
no ip domain-lookup

! Legal notification banner:
banner motd # AUTHORIZED ACCESS ONLY - VIOLATORS PROSECUTED #

! Secure Console line access:
line console 0
 password ciscoconsole
 login
 logging synchronous                 ! Stops syslog console popups from interrupting typing
 exec-timeout 5 0                    ! Disconnects session after 5 mins of inactivity
exit

! Secure VTY remote lines (SSH only):
line vty 0 15
 transport input ssh                 ! Disables unencrypted cleartext Telnet
 password ciscovty
 login
exit
```

## Verification & Diagnostic Commands

| Diagnostic Objective | IOS CLI Command | Critical Output to Verify |
|---|---|---|
| **L1/L2 Interface States** | `show ip interface brief` | `Status: up` (L1) / `Protocol: up` (L2) |
| **IPv6 Interface Verification** | `show ipv6 interface brief`| Verifies `fe80::` Link-Local and configured GUAs |
| **Switchport Mode / Duplex** | `show interfaces status` | Duplex (`a-full` vs `full`), speed, and access VLAN |
| **Interface Counters / MTU**| `show interfaces <id>` | Late collisions, runts, giants, CRC input drops |
| **PoE Power Delivery** | `show power inline` | Available watts, consumed watts, IEEE power class |
| **CAM / MAC Address Table** | `show mac address-table dynamic`| Dynamic MACs mapped to ports and VLANs |
| **Flush MAC Table** | `clear mac address-table dynamic`| Removes dynamically learned CAM entries |
| **CDP Neighbor Discovery** | `show cdp neighbors [detail]` | Local/remote ports, neighbor device ID, remote IP |
| **LLDP Neighbor Discovery** | `show lldp neighbors [detail]`| Open-standard discovery TLVs and remote interfaces |
| **IPv4 Routing Table** | `show ip route` | Connected, local routes, and Gateway of Last Resort |
| **IPv6 Routing Table** | `show ipv6 route` | IPv6 routing prefixes and next-hop LLAs |
| **IPv4 ARP Cache Table** | `show ip arp` | IP-to-MAC resolutions and age timers |
| **IPv6 NDP Neighbor Cache** | `show ipv6 neighbors` | Replaces ARP cache; maps IPv6 to neighbor MAC |
| **SLAAC & RA Inspection** | `show ipv6 interface <id>` | Displays joined multicast groups, RA flags (A/M/O) |
| **System Uptime & Config Reg**| `show version` | Active IOS .bin path, RAM/NVRAM sizes, **0x2102 vs 0x2142** |
| **Display Active Memory Config**| `show running-config` | Active configuration in volatile RAM |
| **Display Saved Startup Config**| `show startup-config` | Configuration in non-volatile NVRAM |
| **Commit Configuration** | `copy running-config startup-config` | Saves RAM to NVRAM (alias: `write`) |
| **Disable CLI Page Pauses** | `terminal length 0` | Suppresses the `--More--` screen prompt for scripting |
